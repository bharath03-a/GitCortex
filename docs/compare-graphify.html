Compare · v0.8.0 vs Graphify 0.9.44

How GitCortex v0.8.0 compares to Graphify 0.9.44.

We indexed the same 5 pinned repositories (ripgrep, requests, hono, cobra, gson) with both GitCortex v0.8.0 and Graphify 0.9.44 (graphify update .), then ran the same 15 impact, architecture, and refactor tasks through Codex CLI (gpt-6.1-sol, low reasoning).

In short

GitCortex v0.8.0 scored 1.000 accuracy (15/15 perfect, 0 errors) while cutting uncached tokens by −32.9% vs grep baseline and indexing 4.8× faster (3.13 s vs 15.08 s). Graphify 0.9.44 scored 0.533 (6/15 perfect) because 5 tasks errored on ambiguous symbols and 3 impact tasks missed callers.

Where Graphify did succeed cleanly (those 6 tasks), Graphify used fewer tokens than both baseline and GitCortex — and Graphify produces smaller JSON graphs on small repos and supports broader multimodal/document inputs. See where Graphify wins.

  • Top rows = Evidence Accuracy (higher is better, max 1.000): Measures whether the assistant returned every required file:line citation with zero forbidden/wrong hits. GitCortex achieves 1.000 on both the 15-task core suite (15/15) and 10-task big-repo suite (10/10).

  • Reading competitor numbers fairly: Graphify’s lower aggregate token bar reflects 5 early exits on ambiguous symbol errors and 9 incomplete/failed tasks (0.533 accuracy); on the 6 tasks where Graphify scored 1.00, it did use fewer tokens (77k vs GitCortex’s 91k). Where Graphify wins (and historical context)

  • Fewer tokens on the 6 tasks where Graphify passed: on the 6-task subset where Graphify scored 1.0 without ambiguity errors, Graphify used 538k total / 77k uncached tokens vs GitCortex's 578k / 91k (and baseline's 891k / 154k).
  • Smaller disk footprint on tiny repos: Graphify's plain JSON store is 3.9–7.5 MiB on cobra, requests, and hono, whereas GitCortex's embedded KuzuDB store has a ~10 MiB baseline floor per branch.
  • Broader non-code & language ecosystem: Graphify supports additional languages plus multimodal docs/PDFs/configs via LLM extraction, whereas GitCortex focuses on zero-LLM, branch-isolated AST code graphs across Rust, Go, Python, TypeScript, Java, and Markdown.

Dated historical note (pre-0.8.0 Claude Code Haiku run): in our earlier 2026 Claude Code comparison, GitCortex scored 0.80 vs Graphify 0.50 (185k vs 244k avg tokens/task). Both tools have improved since then; the Codex v0.8.0 vs Graphify 0.9.44 table above is the current apples-to-apples benchmark.
